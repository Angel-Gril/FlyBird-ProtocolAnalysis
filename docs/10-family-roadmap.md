# 10 · 家族谱系与后续路线

> 本文只描述**谱系与规划**，不包含任何第三方密钥、证书或样本。
> 目标：把「单品牌单协议」的分析扩展成「同族多代协议」的统一处理框架。

---

## 10.1 观察到的事实：同一运营方的多代实现

分析过程中，多个品牌共用同一套 CDN 域名族（`*.llguangli*`）、
同一套「配置发现端点」（`/saos/*.json`）、同一套「伪装 UA + 证书门禁」。

在这些品牌上先后出现过至少三代订阅加密形态：

| 代 | 形态 | 密钥来源 | 完整性 | 特征 |
|---|---|---|---|---|
| **G1** | `base64 → AES-128-CBC(静态 key/iv) → base64 → 明文` | 客户端内置（每品牌一对） | 无 | 固定 IV，无 MAC |
| **G2** | `XOR(内置 key) → base64 → AES-256-GCM(key=SHA256(内置 seed))` | 客户端内置 | GCM tag | 无信封头，nonce 前置 12B |
| **G3** | **APXS v2**：`"APXS" + ver + aesID + signID + nonce + ct + 16B + 64B sig`，AES-256-CTR | 客户端内置常量 k1/k2/k3 | Ed25519 签名 | 有魔数/版本/密钥 ID |

本项目目前**只完整覆盖 G3**（飞鸟 / `ua.net.fbclient.app.apex`），
并额外覆盖该品牌的服务端 **v1 明文线路**。

> G1/G2 的密钥属于其它品牌，**不进入本仓库**。

## 10.2 为什么值得做成"谱系"而不是"单点"

1. **同模板复用**：同一代实现在多个品牌上复用，只是常量与域名不同；
2. **升级路径可预测**：G1 → G2 → G3 的演进显示"加密逐步加码、但密钥始终在客户端"；
3. **检测可泛化**：只要识别出"代数"，就能选对解密器；
4. **安全结论可复用**：三代都存在"密钥内置、全用户共享"，CWE-602 结论一致。

## 10.3 下一阶段规划

### P1 · 家族扫描器（`family_scan.py`）

输入一批样本（安装包/客户端目录），输出统一矩阵：

```
brand | platform | runtime | generation(G1/G2/G3) | key_fingerprint | endpoints | notes
```

判定依据：

- **G3**：二进制中出现 `APXS`、`apex-sub-sign-v2`、105 字节信封特征；
- **G2**：Worker/客户端里出现 XOR 常量 + `SHA-256(seed)` + GCM；
- **G1**：CBC 常量对 + 双重 base64；
- 指纹只记录**常量哈希**（sha256 前 8 位），不记录明文密钥。

### P2 · 解密器插件化

把解密逻辑拆成注册表：

```python
DECRYPTORS = {
    "apxs-v2": decrypt_apxs_v2,     # 已实现
    "v1-plain": v1_plain,           # 已实现（明文线路）
    # 后续：G1/G2 由使用者自带常量加载，不在仓库内置
}
```

命令行统一为：

```bash
apex_fetch.py --source v2|v1|both        # 飞鸟
family_tool.py --generation g2 --key-file ./my.key ...   # 其它代（密钥由使用者提供）
```

**原则**：仓库只提供"算法框架"，密钥由使用者从自己的样本中提取并本地保存。

### P3 · 端点与门禁测绘模板

把本项目的探测方法固化成可复用流程：

1. 证书 purpose 矩阵（api / subscription / oss）
2. UA 矩阵（客户端 UA / 通用 UA / 无 UA）
3. 主机矩阵（api 域 / sub 域 / CDN 域）
4. 404 伪装识别（153 字节 nginx 页为特征）

对应脚本模板见 `tools/cert_matrix.py`、`tools/mitm_observe.py`。

### P4 · 文档补全

- 每代一个 `docs/` 分册（格式、放行条件、节点集特征）
- 谱系对照表（品牌 × 代 × 域名族 × 是否仍在服务）

## 10.4 边界与纪律

| 原则 | 说明 |
|---|---|
| 不内置第三方密钥 | 仓库只放算法与自有品牌常量 |
| 不收录他人凭据 | 证书、token、节点一律不入库 |
| 样本即删 | 分析完立即清理样本与中间产物 |
| 只做授权沙箱 | 每个品牌都需账号所有者授权 |
| 结论可复现 | 任何代数判定都要有脚本可重跑 |
